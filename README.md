# 💪 המאמן — אפליקציית אימונים אישית

אפליקציית אימונים לטלפון: מתח, מקבילים ורצפה, 3 אימונים בשבוע של 30 דקות.

## התקנה באייפון
1. פותחים את הקישור של האתר ב-**Safari**.
2. לוחצים על **שיתוף** ⬆ ואז **הוסף למסך הבית**.
3. מעכשיו זה נפתח כמו אפליקציה רגילה, גם בלי אינטרנט.

## מה יש בפנים
- **אימון יומי** — סבב A (משיכה), B (דחיפה) ו-C (קרב: סקיל + EMOM). יש חימום, טיימר מנוחה אוטומטי וסימון של כל סט.
- **עומס מתקדם** — סגרת את כל הסטים? התרגיל עולה שלב. כשמגיעים לתקרת החזרות עוברים לווריאציה קשה יותר.
- **קרב בוס** — כל 9 אימונים יש מבחן מקסימום, והתוכנית מתכיילת לפי התוצאות.
- **משימת GTG** — סטים קלים של מתח בימי מנוחה, כדי שהמתח יעלה מהר.
- **גלגל פינישים**, **XP ורמות**, **רצף שבועות**, **אתגרים שבועיים**, **28 הישגים**, **עץ סקילס** (מאסל-אפ, L-sit, פיסטול, עמידת ידיים, פרונט לבר).
- **מעקב** — גרף שיאים, גרף היקף מותניים ותמונות לפני/אחרי עם סליידר.

## פרטיות
כל הנתונים והתמונות נשמרים **רק בטלפון** (localStorage / IndexedDB). בקוד אין שום מידע אישי. בהגדרות ⚙️ יש גיבוי ושחזור.

## תמונות מוטיבציה
שמים את התמונות ב-`img/levels/` ומוסיפים אותן ל-`MOTIVATION_IMAGES` בקובץ `js/data.js`:
```js
{ level: 3, src: 'img/levels/level-3.jpg', caption: 'ככה זה ייראה' }
```
כל תמונה נפתחת כשמגיעים לרמה שלה.

## סרטון מוטיבציה בפתיחה
בכל פתיחה של האתר (וגם כשחוזרים אליו אחרי 10 דקות ברקע) מתנגן סרטון מוטיבציה במסך מלא. נגיעה במסך סוגרת אותו, וכפתור 🔇 מדליק סאונד.
הסרטון **לא נמצא באתר הציבורי**: הוא שמור בריפו הפרטי בנתיב `motivation/intro.mp4`, ומופיע רק בטלפון שמחובר לריפו הפרטי בהגדרות ⚙️.
כדי להחליף סרטון מעלים קובץ חדש לאותו נתיב בריפו הפרטי. הטלפון מוריד אותו לבד בפתיחה הבאה.

## עדכון גרסה
אחרי כל שינוי בקבצים מעלים את `CACHE` בקובץ `sw.js` (למשל `trainer-v2`), כדי שהטלפון יקבל את הגרסה החדשה.
