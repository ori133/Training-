# המאמן — אפליקציית אימונים אישית

אפליקציית אימונים לטלפון: מתח, מקבילים ורצפה, 3 אימונים בשבוע של 30 דקות.

## התקנה באייפון
1. פותחים את הקישור של האתר ב-**Safari**.
2. לוחצים על **שיתוף** ואז **הוסף למסך הבית**.
3. מעכשיו זה נפתח כמו אפליקציה רגילה, גם בלי אינטרנט.

## מצב אימון — בלי להתעסק עם הטלפון
לוחצים **התחל אימון** והמסך עובר למצב אימון מלא: דבר אחד בכל פעם, באותיות ענקיות.
- **סט = נגיעה אחת** בכל מקום במסך. עשית פחות או יותר? כפתור קטן ובוחרים מספר.
- **המנוחה רצה לבד**, ובסופה התרגיל הבא מופיע לבד.
- **המאמן מדבר**: מקריא בעברית מה עכשיו ומה הבא (אפשר להשתיק בכפתור הרמקול).
- **חימום, פלאנק והחזקות, סקיל ו-EMOM** רצים לבד עם טיימר וצפצופים.
- **בסוף**: קל / בדיוק / קשה, ואפשר לתקן מספרים שטעית בהם.
- כפתור הרשימה למעלה פותח את התצוגה המלאה הישנה. המסך נשאר דלוק כל האימון.

## מה יש בפנים
- **אימון יומי** — סבב A (משיכה), B (דחיפה) ו-C (קרב: סקיל + EMOM). יש חימום, טיימר מנוחה אוטומטי וסימון של כל סט.
- **עומס מתקדם** — סגרת את כל הסטים? התרגיל עולה שלב. כשמגיעים לתקרת החזרות עוברים לווריאציה קשה יותר.
- **קרב בוס** — כל 9 אימונים יש מבחן מקסימום, והתוכנית מתכיילת לפי התוצאות.
- **משימת GTG** — סטים קלים של מתח בימי מנוחה, כדי שהמתח יעלה מהר.
- **גלגל פינישים**, **XP ורמות**, **רצף שבועות**, **אתגרים שבועיים**, **28 הישגים**, **עץ סקילס** (מאסל-אפ, L-sit, פיסטול, עמידת ידיים, פרונט לבר).
- **מעקב** — גרף שיאים, גרף היקף מותניים ותמונות לפני/אחרי עם סליידר.

## פרטיות
כל הנתונים והתמונות נשמרים **רק בטלפון** (localStorage / IndexedDB). בקוד אין שום מידע אישי. בהגדרות יש גיבוי ושחזור.

## תמונות מוטיבציה
שמים את התמונות ב-`img/levels/` ומוסיפים אותן ל-`MOTIVATION_IMAGES` בקובץ `js/data.js`:
```js
{ level: 3, src: 'img/levels/level-3.jpg', caption: 'ככה זה ייראה' }
```
כל תמונה נפתחת כשמגיעים לרמה שלה.

## סרטון מוטיבציה בפתיחה
בכל פתיחה של האתר (וגם כשחוזרים אליו אחרי 10 דקות ברקע) מתנגן סרטון מוטיבציה במסך מלא. נגיעה במסך סוגרת אותו. הסרטון תמיד מנסה להתחיל עם סאונד. אם הטלפון חוסם סאונד אוטומטי (אייפון, בפתיחה ראשונה), הוא מתחיל בשקט עם כפתור השתקה, ואחרי הנגיעה הראשונה הכניסות הבאות מתחילות עם סאונד.
הסרטון **לא נמצא באתר הציבורי**: הוא שמור בריפו הפרטי בנתיב `motivation/intro.mp4`, ומופיע רק בטלפון שמחובר לריפו הפרטי בהגדרות.
כדי להחליף סרטון מעלים קובץ חדש לאותו נתיב בריפו הפרטי. הטלפון מוריד אותו לבד בפתיחה הבאה.

## אייקונים
כל האייקונים מצוירים ב-SVG בקובץ `js/icons.js` (אין אימוג'י). משתמשים בהם עם `ic('שם')`.

## עדכון גרסה
אחרי כל שינוי בקבצים מעלים את `CACHE` בקובץ `sw.js` (למשל `trainer-v2`), כדי שהטלפון יקבל את הגרסה החדשה.
